# 城市匹配度测试 · 前端需求文档

**项目名称**：城市灵魂匹配测试  
**版本**：v1.0  
**目标上线平台**：移动端H5（主），PC端自适应（次）  
**核心用户**：18-30岁年轻女性，小红书/微信生态用户

---

## 一、项目概述

### 1.1 产品定位
一款娱乐向的性格匹配测试H5，用户通过回答30道生活场景题，匹配出最契合自己气质的中国城市（共10个城市结果）。

### 1.2 核心目标
- 让用户愿意完成30道题（不中途流失）
- 让用户看到结果后愿意截图分享到社交平台
- 整体体验感受：美、舒服、有质感、想发朋友圈

### 1.3 用户画像
| 特征 | 描述 |
|------|------|
| 年龄 | 18-30岁为主 |
| 性别 | 女性为主（约80%） |
| 平台 | 小红书、微信、微博 |
| 审美偏好 | 喜欢"好看的东西"，对粗糙/土气的设计敏感 |
| 使用场景 | 碎片时间消遣、朋友分享后点开、刷到小红书笔记后进入 |
| 心理预期 | "测着玩玩"但希望结果"有点准"、"说得挺对" |

## 二、整体氛围定义

### 2.1 关键词（请贯穿整个设计）

**必须有的感觉：**
- 质感（不廉价、不像普通问卷）
- 舒适（不刺眼、不疲劳）
- 轻盈（不沉重、不严肃）
- 精致（细节经得起放大看）
- 温柔（不冷冰冰、有人情味）

**绝对要避免的感觉：**
- 土 / 廉价 / 像广告弹窗
- 过于花哨 / 元素太多太杂
- 严肃 / 像正经心理测试
- 冷淡 / 没有温度
- 像政府问卷 / 企业调研

### 2.2 情绪曲线
整个测试体验应该像"一次轻松的散步"：

```
开始 → 做题过程 → 结果揭晓
轻松好奇   沉浸流畅   小惊喜+满足
```

- **开始**：让用户觉得"这个看起来不错，想试试"
- **做题**：不觉得累，甚至有点享受（像在做一本精美的杂志问答）
- **结果**：有仪式感，结果呈现让人想截图

### 2.3 风格参考方向

以下方向供设计师参考，不强制使用，核心是"年轻女性会觉得美"：

| 风格方向 | 说明 | 适合程度 |
|----------|------|----------|
| 杂志感/Editorial | 大留白、优雅排版、像翻一本生活杂志 | ⭐⭐⭐⭐⭐ |
| 轻奶油风 | 低饱和、柔和、温暖、不刺眼 | ⭐⭐⭐⭐⭐ |
| 极简文艺 | 少即是多、注重字体和间距 | ⭐⭐⭐⭐ |
| 插画风 | 有原创插画点缀（如果预算允许） | ⭐⭐⭐⭐ |
| 玻璃拟态/毛玻璃 | 有质感但不过度 | ⭐⭐⭐ |
| 霓虹赛博 | 太冷、太酷、不适合本产品 | ❌ |
| 商务简约 | 太正式、没有温度 | ❌ |

### 2.4 色彩方向建议

**主色调思路：**
- 低饱和度、高明度为主
- 让人感觉"舒服"而非"刺激"
- 可以有1个点缀色用于强调（如按钮、进度）

**参考色系（非强制，供参考）：**
- 米白/奶油色系（温暖）
- 莫兰迪色系（高级感）
- 淡蓝灰/雾霾蓝（文艺）
- 裸粉/脏粉（柔和女性化但不幼稚）

**避免：**
- 高饱和大红大绿
- 纯黑/纯白大面积使用（太冷）
- 荧光色（廉价感）

## 三、页面结构与功能需求

整个H5共4个主要页面/状态：

### 3.1 首页（开始页）

**功能：** 吸引用户开始测试

**需要的元素：**
- 测试标题
- 一句话简介/引导语
- 开始按钮
- （可选）底部小字：测试仅供娱乐

**文案参考：**
```
标题：你的灵魂属于哪座城市？
副标题：30道小问题，找到最懂你的那座城
按钮：开始测试
```

**氛围要求：**
- 简洁，不堆砌
- 有一点"打开一本书"的仪式感
- 让人觉得"这个测试不一样"

**设计空间：**
- 可以考虑有一个主视觉（城市剪影/抽象图形/插画）
- 或者纯文字+大留白的杂志感
- 设计师可自由发挥

---

### 3.2 答题页

**功能：** 用户逐题作答，共30题

**核心元素：**
- 当前题目序号/总题数（如 3/30）
- 进度指示（进度条或其他形式）
- 题目文字
- 4个选项（A/B/C/D）
- （可选）上一题按钮

**交互逻辑：**
- 点击选项后，短暂反馈（如选项变色/轻微动效），然后自动进入下一题
- 不需要单独的"确认"或"下一题"按钮
- 答题过程应该是流畅的、无打断的
- 最后一题作答后，自动进入加载/结果页

**氛围要求：**
- 这是用户停留最久的页面，必须"耐看"
- 阅读舒适：字号适中、行距舒服、对比度够但不刺眼
- 选项区域点击热区要够大（移动端友好）
- 进度感知：让用户知道自己在哪里、还有多少

**设计注意：**
- 30道题不算少，如何让用户不觉得累是关键
- 可以考虑：每答5-10题有微小变化（背景色渐变、氛围元素变化）
- 或者保持极简一致，靠质感取胜
- 选项不要用单选框/勾选框的传统表单样式

**字体建议：**
- 题目文字要清晰易读
- 选项文字稍小于题目，但不能太小
- 中文字体选用思源黑体/苹方/阿里普惠体等现代简洁字体
- 避免宋体/楷体等传统印刷体

---

### 3.3 加载页（结果计算中）

**功能：** 在答题完成和结果展示之间，给一个短暂的过渡

**时长建议：** 2-3秒（太短没有仪式感，太长用户会不耐烦）

**可以展示：**
- 一句话（如"正在匹配你的城市灵魂..."）
- 轻量动效/加载动画
- 或者城市剪影逐渐浮现

**氛围要求：**
- 制造一点点"期待感"
- 不要用传统的转圈loading
- 应该是有设计感的等待，而不是"系统正在处理"的感觉

---

### 3.4 结果页（最重要）

**功能：** 展示用户的匹配城市，引导分享

**这是整个产品最核心的页面——用户截图分享的就是这个页面。**

**必须包含的元素：**
- 城市名称（大而醒目）
- 城市副标题（如"松弛感满分的生活艺术家"）
- 标签（3-4个关键词，如 #会生活 #烟火气 #慢节奏）
- 金句（一句话概括，适合截图）
- 人格描述（3-5段文字，核心内容）
- 生活方式建议（可选展示）
- 分享/保存按钮
- 重新测试按钮

**布局建议（分层展示）：**

```
第一屏（截图核心区）：
┌─────────────────────────┐
│      [ 城市主视觉 ]      │
│                         │
│     上 海               │
│     精致主义的都市弄潮儿  │

│  #国际视野 #要强但体面   │

│  精致是一种尊重。」      │
│                         │

└─────────────────────────┘

向下滚动（详细内容）：
┌─────────────────────────┐
│                         │
│   你骨子里有一种"要做就  │
│   做最好"的劲儿……       │

```

**第一屏设计要求（重中之重）：**
- 比例适合手机截图（宽高比约9:16或接近）
- 信息完整但不拥挤
- 视觉上"值得发朋友圈"
- 有品牌感/识别度

**城市主视觉方向：**
- 每个城市需要一个视觉元素区分（共10个城市）
- 可以是：城市插画、标志性元素抽象化、代表色+图形、摄影图叠加处理
- 设计师可提案不同方向

## 四、交互与动效

### 4.1 总体原则
- 轻量、流畅、不抢戏
- 动效是"加分项"而非"必需品"
- 宁可没有动效，也不要卡顿的动效

### 4.2 建议有的交互

| 场景 | 建议交互 |
|------|----------|
| 点击开始按钮 | 按钮微微放大或颜色变化，页面平滑过渡 |
| 选择选项 | 选中状态反馈（变色/边框/轻微放大），短暂停留后滑入下一题 |
| 题目切换 | 平滑过渡（淡入淡出或左右滑动） |
| 进度条 | 平滑增长，不要跳跃 |
| 结果出现 | 可以有一个"揭晓"的仪式感动效（如淡入、从模糊到清晰、元素依次出现） |

### 4.3 避免的交互
- 弹窗打断
- 强制等待
- 复杂的3D/粒子效果（移动端性能隐患）
- 自动播放的音频

---

## 五、技术与适配要求

### 5.1 响应式
- 移动端优先（主战场）
- 建议以375px宽度为基准设计
- 需适配大屏手机（414px、428px等）
- PC端可简单适配或居中展示手机视图

### 5.2 性能要求
- 首屏加载时间 < 3秒（4G网络）
- 图片压缩、懒加载
- 避免大体积动效库

### 5.3 分享功能
- 结果页需要支持"保存为图片"功能
- 生成的图片应该是第一屏内容，比例适合分享
- 图片上可以带一个小logo或二维码（引导回流）

### 5.4 浏览器兼容
- 微信内置浏览器（必须）
- Safari（iOS）
- Chrome（Android）
- 小红书内置浏览器

- [ ] 30道题可正常作答

## 八、附录：设计师自由发挥空间

以下部分不做强制规定，由设计师根据理解自行创作：

1. **首页主视觉创意** —— 可以是城市剪影组合、抽象图形、插画、或纯文字
2. **答题页的氛围营造** —— 如何让30道题不无聊
3. **进度条/进度指示的形式** —— 不一定是传统进度条
4. **结果页的城市视觉风格** —— 统一风格还是每个城市不同风格
5. **微动效设计** —— 在不影响性能的前提下自由添加
6. **字体组合与排版细节** —— 在保证可读性的前提下自由发挥
